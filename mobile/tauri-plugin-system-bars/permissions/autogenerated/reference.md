## Default Permission

Allows the app to match the system bar icons to its own theme

#### This default permission set includes the following:

- `allow-set-appearance`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`system-bars:allow-set-appearance`

</td>
<td>

Enables the set_appearance command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`system-bars:deny-set-appearance`

</td>
<td>

</td>
</tr>
</table>
